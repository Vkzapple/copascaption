# CopasCaptionPop🌸✨

A cute pink and yellow yups yups **caption & hashtag generator**.
Enter a topic or a photo description, pick a platform (Instagram, LinkedIn, or X), and get **3 caption options with hashtags** as JSON. No API key, no internet, just a local (traditional) AI model `model.pkl` LMAO.

## Features

- Topic or photo-description input
- Platform-aware output for Instagram, LinkedIn, and X
- 3 options per request: playful, storytelling, and punchy
- Hashtags built from your keywords plus a category pool
- Raw JSON view and one-click copy
- Light and dark mode

## How it works
 
`model.pkl` holds two scikit-learn pipelines (TF-IDF + Logistic Regression), both trained on the bilingual dataset:
 
1. **Category model**: classifies the input as food, travel, fashion, career, tech, fitness, business, or lifestyle.
2. **Language model**: detects whether the input is English or Indonesian.
`content.py` then fills caption templates for that category and language, and adapts them to the platform:
 
- **Instagram**: emojis, up to 10 hashtags, photo-style openers in photo mode
- **LinkedIn**: no emojis, a discussion closer, 5 hashtags
- **X**: caption plus hashtags kept under 280 characters, 2 hashtags
`app.py` exposes everything through a small Flask API.
 
> The models classify the input and the captions come from templates, so output is consistent but not freely generated like an LLM.

## API
 
`POST /api/generate`
 
```json
{
  "topic": "Launching kopi susu gula aren di kafe baru kami",
  "platform": "Instagram",
  "mode": "topik"
}
```
 
- `platform`: `Instagram`, `LinkedIn`, or `X`
- `mode`: `topik` (topic) or `foto` (photo description)
Response:
 
```json
{
  "platform": "Instagram",
  "mode": "topik",
  "topic": "Launching kopi susu gula aren di kafe baru kami",
  "category": "kuliner",
  "confidence": 0.97,
  "options": [
    {
      "id": 1,
      "style": "Lucu & Playful",
      "caption": "...",
      "hashtags": ["#kuliner", "#kopi"]
    }
  ]
}
```
